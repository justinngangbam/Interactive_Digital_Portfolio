My Projects

Motor Thrifters - Online Used Vehicles Marketplace

Motor Thrifters is a web application designed to simplify the process of buying and selling used vehicles. The platform allows users to register, list vehicles, manage their inventory, and connect with potential buyers. With secure authentication, user roles, and an intuitive dashboard for both admins and users, Motor Thrifters streamlines vehicle management and marketplace interactions, making it easy for anyone to find or sell a car online.

Technologies Used

Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express
Database: MongoDB
IDE: Visual Studio Code
